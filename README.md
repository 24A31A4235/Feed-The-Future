# 🍲 Feed The Future

A food donation platform that connects restaurants with surplus food to people in need.

## What it does
- Restaurants list leftover food on the website.
- Workers see the details, collect the food and deliver it to needy people.
- A store section lists government subsidised products that visitors can buy and add to cart.

## 🚀 How to Run
Open `index.html` in a browser to view the site. To use the donation and cart features, run the folder on a PHP server instead, e.g. `php -S localhost:8000` from the project folder, with the database settings in `config.php`.

## 🛠️ Tech Stack
- HTML, CSS, JavaScript
- PHP (donation and cart features)
- Bootstrap
